# Zdrapka górska – mapy

Paczki map do aplikacji **Zdrapka górska**. Aplikacja pobiera stąd mapę regionu raz, a potem działa bez internetu.

Tylko dane publiczne:

- © współtwórcy [OpenStreetMap](https://www.openstreetmap.org/copyright), licencja [ODbL](https://opendatacommons.org/licenses/odbl/)
- Copernicus DEM GLO-30 © DLR e.V. 2010–2014 i © Airbus Defence and Space GmbH 2014–2018, udostępniony w ramach programu Copernicus

`maps.json` to lista regionów; `<region>/files.json` – pliki paczki z rozmiarami.
