# Height grid for "Szczyty w aparacie"

`sudety.hdem.gz`: Copernicus GLO-90 DEM (© DLR e.V., © Airbus) over the Sudety and ~100 km round them
(13.2–19.3°E, 49.0–52.0°N), 3" × 4.5" cells, gzipped HDEM (see scratchcard `tools/horizon_dem.py`).
Read by the app from raw.githubusercontent.com (this branch is not part of the maps site on Pages).
